# Mini Hospital Emergency Management System

## Overview
A Java-based emergency management system implemented using foundational Data Structures.

## Implemented Data Structures
- **Binary Search Tree (BST):** Patient Records Management (Insert, Search, Delete, In-order Traversal)
- **Queue (FIFO):** Emergency Patient Queue (Enqueue, Dequeue, Display)
- **Stack (LIFO):** Treatment History Management (Push, Pop, Display)
- **Singly Linked List:** Patient Visit History (Add, Remove, Search, Display)

## How to Run
1. Clone the repository.
2. Open the project in VS Code / IntelliJ IDEA.
3. Run `src/main/Main.java`.
